## 1. 지금 상태 (세어 본 결과)

중급에서 배우는 문장이 고급에 **그대로 나오는 곳은 한 군데도 없습니다.** 낱말만 겹칩니다.

| 중급에서 배우는 것 | 수 | 고급에 그대로 나오는 수 |
|---|---|---|
| 받아쓰기 3단계 생활 문장 | 12 | 0 |
| 3부 짧은 글 읽기 (글 6편, 18문장) | 18 | 0 |
| 1·2단계 인사말 | 22 | 4개만 (안녕하세요·고맙습니다·죄송합니다·축하합니다) |

(자료: `tools/dictation/문장목록.json`, `tools/dictation/build.js` 의 `SENT1`·`SENT2`, `go/index.html` 을 맞대어 셈)

고급 **제3과 「아는 말에서 시작하기」** 가 이미 다리 노릇을 합니다. 다만 **낱말 짝**(주다 → 신청, 가지고 가다 → 지참)이고,
**문장**으로 이어 주는 곳은 없습니다.

## 2. 어떻게 — 추천안

**고급의 각 과 문제 목록에 「중급에서 쓴 문장」 문제를 한두 개씩 넣습니다.**

- 새 기능 없음. 지금 있는 문제 틀(안내문을 보여 주고 고르기, 차례 맞추기)을 그대로 씁니다.
- 물음 앞에 「중급에서 이렇게 썼지요.」를 붙여, **아는 문장 → 진짜 문서의 말**로 건너가게 합니다.
- 졸업 시험은 각 과 문제에서 고르므로, 새 문제도 저절로 섞여 나옵니다.

## 4. 녹음할 말 (선생님 검토 뒤 PC에서 한 줄로)

고급은 물음과 보기를 소리로 읽어 줍니다. 그래서 새 문제마다 물음 1개와 보기 3개를 녹음합니다.

| 무엇 | 수 |
|---|---|
| 1~7, 9번 물음과 보기 | 8 × 4 = 32 |
| 8번 차례 맞추기 (다 맞춘 문장 하나) | 1 |
| 풀이 글 | 0 (고급은 풀이를 녹음하지 않습니다) |
| **모두** | **33개 이하** (이미 녹음된 보기와 겹치면 줄어듭니다. 정확한 수는 만든 뒤 `go/tools/extract_used.js` 로 셉니다) |

PC에서 `tools/pc_record.py` 한 줄이면 됩니다. 녹음 전에는 지금처럼 🔊 없이 글로만 나옵니다.
