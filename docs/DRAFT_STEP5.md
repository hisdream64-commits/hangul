## 2. 어디에, 어떻게

- **기초 학습**에 탭을 하나 더: 「1단계 자음 · 2단계 모음 · 3단계 소리 합치기 · 4단계 받침 읽기 · **5단계 더 배우는 글자**」
- 화면은 **1·2단계와 똑같이** 합니다. 큰 글자 → 이름 → 소리 → 보기 낱말, 「◀ 이전 · 🔊 다시 듣기 · 다음 ▶」.
  어르신이 이미 익숙한 방식이라 새로 배울 사용법이 없습니다.
- 소리도 같은 세 도막: 「이 글자의 이름은, 쌍기역.」 → 「소리는, 끄.」 → 「예를 들면, 토끼.」
- 진도 저장(지난번 자리에서 이어 하기)에도 그대로 들어갑니다.
- 5단계는 네 묶음으로 나눠, 묶음이 바뀔 때 짧은 안내를 한 번 들려줍니다(아래 3절의 「묶음 안내」).

## 7. 이번에는 하지 않는 것 (나중에 따로)

- 3단계 「소리 합치기」에 쌍자음·새 모음 넣기 (예: ㄲ + ㅏ → 까). 녹음이 많이 늘어 따로 정합니다.
- ㄲ·ㅆ 받침(밖, 있다)과 4단계 받침 읽기 연결.
- 「글씨 쓰기 연습」의 쓰는 순서 그림(GIF)에 새 글자 16개 더하기. 그림을 새로 만들어야 합니다.
- 「글자 한눈에 보기」에 새 글자 넣기 — 5단계를 만든 뒤 같이 넣을지 정합니다.
