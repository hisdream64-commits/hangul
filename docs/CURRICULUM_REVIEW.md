# 한글뚝딱 교육과정 현황 분석 (2026-11-07)

[PRINCIPLES.md](PRINCIPLES.md)의 기본 전제를 기준으로 초급·중급·고급을 분석했습니다. **코드는 고치지 않았습니다.**
숫자는 각 화면의 실제 자료를 세어 낸 것이고, 문서에서만 가져온 것은 따로 적었습니다.
기준은 하나입니다: **글을 잘 못 읽는 성인이 집에서 혼자, 휴대폰으로, 인터넷 없이 공부할 수 있는가.**

## 2. 반별 목표 대비 현황

### 초급 — 한글 기초 해득

| 목표 | 판정 | 근거 |
|---|---|---|
| 자음과 모음 이해 | **부분** | 기본 자음 14, 기본 모음 10만 가르침. **쌍자음 5개(ㄲㄸㅃㅆㅉ)와 모음 11개(ㅐㅒㅔㅖㅘㅙㅚㅝㅞㅟㅢ)가 없음** |
| 글자 조합과 소리 이해 | 충족 | 3단계 소리 합치기 140글자, 붙여 읽기 → 빠르게 → 글자 |
| 받침 학습 | 충족 | 4단계 받침 14종 41낱말, 예외(ㄱ·ㄷ·ㅅ) 경고 |
| 기초 낱말 읽기와 쓰기 | **부분** | 읽기는 그림 놀이 하나. **낱말 쓰기 활동 없음.** 글씨 쓰기는 자모 24자 쓰는 순서 그림 보기뿐 |
| 생활 속 기본 어휘 | 충족 | 15갈래 758낱말, 녹음 100% |

**잘된 점**
- 글자 이름과 소리를 나눠 가르칩니다. 「기역」은 이름, 「그」는 소리입니다.
- 소리 합치기와 받침 읽기를 귀로 들려줍니다. 2026-11-07부터 1.25배로 붙여 읽은 뒤 2.5배로 뭉칩니다.
- 첫 화면을 소리로 안내하고, 지난번 자리에서 이어 합니다.
- 인터넷 없이 쓰고, 홈 화면에 담을 수 있습니다.

**개선할 점**
1. **쌍자음·복잡한 모음을 배우지 않는데 낱말에는 많이 나옵니다.** 낱말 758개 가운데 185개(24%)에 ㅐ·ㅔ·ㅘ 같은 모음, 51개에 쌍자음이 있습니다. 앱 이름 「뚝딱」의 ㄸ도 배우지 않습니다. 중급 1단계 「베개」에도 ㅔ가 나옵니다.
2. **낱말이 주제별로만 묶여 있습니다.** 758개 중 568개(75%)가 받침 있는 낱말입니다. 「받침 없는 쉬운 낱말 → 받침 있는 낱말」 순서가 없어서, 4단계를 막 마친 분이 바로 읽기 어려운 낱말을 만납니다.
3. **쓰기가 거의 없습니다.** 자모 쓰는 순서 그림만 보고, 써 보는 칸은 없습니다(11절 ⑨).
4. **읽기를 확인하는 활동이 적습니다.** 낱말 카드는 누르면 소리가 나서, 읽지 않고 들어도 됩니다. 읽기 확인은 그림 놀이 하나이고, 그 보기도 들을 수 없습니다(11절 ⑤).
5. 「글자 한눈에 보기」는 1·2단계와 같은 내용을 다시 보여 줍니다.
6. 낱말 가운데 67%에 그림이 없습니다. 명절 3/36, 하는 말 3/62, 마음 2/50입니다(11절 ⑧).
7. 단추 이름이 글자뿐입니다(11절 ③). 틀린 것만 다시 풀기가 없습니다.

### 중급 — 낱말 및 문장 이해와 표현

| 목표 | 판정 | 근거 |
|---|---|---|
| 다양한 낱말 읽기와 쓰기 | 부분 | 쓰기만 있음(78개). 읽고 고르는 활동 없음 |
| 받침 및 겹받침 이해 | 충족 | 1부 2~4단계, 겹받침 11가지·활동 4가지 |
| 낱말 받아쓰기 | 충족 | 1부 전체, 겹받침 듣고 쓰기 |
| 문장 읽기와 받아쓰기 | 부분 | 34문장을 카드로 받아쓰기. 직접 써 넣기나 문장 읽기는 없음 |
| 띄어쓰기와 문장 구성 | 부분 | 칸 수가 정해져 있어 순서만 고름 |
| 짧은 글 읽기와 내용 이해 | **없음** | 글과 이해 문제가 없음 |
| 생각과 경험을 문장으로 | **없음** | 자유 쓰기 없음 |

**잘된 점**
- 받아쓰기의 짜임이 좋습니다. 받침 없음 → 있음 → 소리와 글자가 다름 → 겹받침 순서로 어려워집니다.
- 틀린 자리를 첫소리·가운뎃소리·받침으로 짚어 주고, 소리를 다시 들려줍니다.
- 오답 카드가 실제로 많이 틀리는 글자입니다(감니다, 머거써요).
- 화면 글과 녹음이 다르면 만들기 도구가 일부러 실패합니다.
- 종이에 쓰는 방법도 있습니다.

**개선할 점**
1. **안내, 오답 이유, 틀린 말 목록이 모두 글자뿐입니다.** 글을 못 읽는 분은 혼자 진행하기 어렵습니다.
2. 짧은 글 읽기, 자기 생각 쓰기가 없습니다.
3. 1부에 그림이 없습니다. 초급에는 78개 중 39개에 그림이 있습니다.
4. 틀린 것만 다시 풀기가 없고, 중간 진도도 저장하지 않습니다.
5. 중급만 홈 화면에 담고 초급을 한 번도 안 열면, 인터넷 없이 소리가 나지 않습니다.

**확실한 오류 3가지** (코드에서 직접 확인)
- 겹받침 「어느 쪽 소리가 날까요」의 ㄿ(읊다) 문제는 정답이 「ㅂ」인데 보기가 「ㄹ」「ㅍ」뿐이라 **맞힐 수 없습니다** (`tools/dictation/build.js:123`, `gyeopbatchim.html:733`).
- 「받침 채워 쓰기」는 맞을 때까지 다시 고르게 하고 맞은 것만 세서 **점수가 늘 만점**입니다 (`gyeopbatchim.html:602-608`).
- 겹받침 설명의 「닭을[다글]」은 표준 발음이 **[달글]**입니다 (`gyeopbatchim.html:559`).

그 밖에 3단계 설명은 "낱말 소리를 들어 볼 수 있다"고 하지만, 통문장 녹음이 있으면 낱말 소리 단추가 숨겨집니다. 겹받침 낱말 25개 중 14개(넋, 몫, 삶, 여덟, 읊다 등)는 녹음이 없습니다.

| 목표 | 판정 | 근거 |
|---|---|---|
| 생활 속 안내문과 정보 읽기 | 충족 | 3·5·6·10과, 문서 보고 답하는 문항 15개 |
| 공공기관·관공서 용어 | 충족 | 3과(신청·접수·구비 서류·지참·감면·회신) |
| 다양한 생활 서식 작성 | 부분 | 서식의 칸 위치만 고르고, 실제로 채워 쓰지 않음 |
| 편지와 문자 작성 | 부분 | 본보기와 조각 차례 맞추기뿐 |
| 긴 글 읽기와 내용 이해 | 부분 | 가장 긴 문서가 152자 |
| 정보 탐색 및 활용 | 부분 | 검색 안내 카드 1장, 문서에서 날짜·금액 찾기 |
| 생각과 의견을 글로 | **없음** | 쓰는 칸이 하나도 없음 |

**잘된 점**
- 실제 생활 문서가 약 30종입니다. 사기 문자, 약 봉투, 처방전, 고지서, 부고, 청첩장처럼 어르신 생활에 꼭 맞는 소재입니다.
- 녹음이 빠짐없이 있고, 인터넷 없이 씁니다.
- 활동이 여러 가지이고, 졸업 시험이 있습니다.

**개선할 점**
1. **물음과 보기 96문항을 읽어 주지 않습니다.** 차례 맞추기 조각도 읽어 주지 않습니다.
2. 문서 카드 43장 가운데 33장은 녹음이 문서 전체가 아니라 요약입니다. 화면 글과 들리는 말이 다릅니다.
3. **CLAUDE.md 규칙과 어긋납니다.** 「🐢 천천히 듣기」가 재생 빠르기를 0.72배로 바꾸고(`go/index.html:1397`), 녹음이 없으면 기계 음성으로 넘어갑니다.
4. **실제로 쓰는 활동이 없습니다.** 서식 작성, 편지·문자 작성, 의견 쓰기가 비어 있습니다.
5. 결과 화면이 "틀린 것만 한 번 더 보시면"이라고 말하지만, 그런 기능은 없습니다(`go/index.html:1687`).
6. 과에 들어가도 첫 카드나 첫 물음이 저절로 소리 나지 않습니다. 권장 순서나 "다음 과" 안내도 없습니다.
7. 12과 「소리 내어 읽기」는 실제 휴대폰에서 확인하지 않았습니다. 인터넷 없이 되는지도 확실하지 않습니다(`go/MIGRATION.md` 9-1절, 문서 기준).

## 3. 단계별 교육과정의 연계성

### 이어지는 것
- **초급 낱말 → 중급 받아쓰기**: 중급 1부 낱말 78개와 인사말 22개는 **모두 초급 낱말 목록에 있습니다.** 초급에서 듣고 본 낱말을 중급에서 씁니다. 원칙 3의 "초급 낱말이 중급으로"가 가장 잘 지켜진 곳입니다.
- **이동 링크**: 중급 → 초급·고급, 겹받침 → 중급·초급, 고급 → 초급·중급 링크가 있습니다.
- **같은 목소리와 같은 저장 방식**: 세 반 모두 같은 성우(edge-tts SunHi)이고, 휴대폰 안에 진도를 저장합니다.

### 끊긴 곳

| 어디 | 무엇이 끊겼나 |
|---|---|
| 초급 → 중급 | 초급은 쌍자음·복잡한 모음을 가르치지 않는데, 중급 첫 단계부터 「베개」(ㅔ)가 나옴 |
| 초급 → 중급 | 초급에 쓰기 활동이 거의 없다가, 중급에서 갑자기 받아쓰기가 시작됨 |
| 초급 → 고급 | **초급 첫 화면에는 고급으로 가는 링크가 없음** (중급·겹받침만 있음) |
| 중급 → 고급 | 중급 생활 문장 12개 중 고급에 다시 나오는 문장은 0개. 고급은 중급 문장을 생활 문서로 넓히지 않음 |
| 중급 → 고급 | 중급에 「짧은 글 읽기」가 없어서, 고급의 안내문·긴 글 읽기로 넘어가는 다리가 없음 |
| 세 반 공통 | **쓰기**가 초급(없음) → 중급(카드·자모 판) → 고급(누르기만)으로 이어지지 않음. 원칙 3의 "읽기·듣기·쓰기·이해하기 균형"에서 쓰기가 가장 약함 |
| 세 반 공통 | **틀린 것만 다시** 기능이 세 반 모두 없음. 원칙 4의 "정답 확인 → 다시 연습하기" 고리가 끊김 |
| 세 반 공통 | **소리 안내 수준이 다름**. 초급은 첫 화면을 소리로 안내하지만 중급·고급은 안내가 글자뿐 |
| 세 반 공통 | 어느 반부터 하면 좋을지 알려 주는 진단이나 안내가 없음 |
